View-Batch Replay for Continual Learning
毕业设计 | Python + PyTorch | 2026.01 - 至今
CVPR 2025 毕业论文
复现CVPR 2025论文《Replay Compression for Class-Incremental Learning》(arXiv:2503.18371v1)，受认知心理学间隔效应启发，实现View-Batch Replay机制缓解神经网络灾难性遗忘。
  • 论文复现：完整实现View-Batch Replay采样机制、渐进式数据增强、KL散度一致性损失
  • 改进探索：测试不同aug_repeat参数(2/4/8)和多种渐进式增强策略，发现高斯噪声效果最佳
  • 实验结果：CIFAR-10类增量学习(5任务)，准确率从71.67%提升至72.97%，遗忘率降低50.8%

强化学习

GNN-Transformer for Trajectory Prediction
独立复现 | Python + PyTorch Geometric | 2024.09 - 2025.03
VectorNet 自动驾驶
复现Waymo VectorNet论文，构建层次化图神经网络与Transformer相结合的深度学习模型，用于自动驾驶场景中的多代理轨迹预测。
